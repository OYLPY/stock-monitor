# P02-02 交接

## Objective

设计美日行情、公司 IR、SEC/EDINET/TDnet 披露、新闻和经济日历的来源边界与统一证据契约；区分来源时间、市场时间、采集时间、时效、可用性和验证等级，并确保缺失、冲突、过期或 Fixture 数据不会成为正式信号。

## Established facts

- SEC EDGAR 提供申报历史和派生 XBRL 数据；接受时间不等于首次可见时间，公开可见延迟没有保证。自动访问需声明 User-Agent 并遵守总计 10 req/s 的限制。
- EDINET API v2 需要 API key；书类清单会更新，清单项不保证当前可下载。`submitDateTime`、`opeDateTime` 和清单 `processDateTime` 语义分别保留。
- JPX 有公开 TDnet 网页，但 API/历史服务为付费服务；测试服务器返回 dummy data。当前不接付费接口，也不把网页可见等同于自动获取/再分发许可。
- 还没有选择或验证行情供应商；条款、样本、时效、费用和覆盖须留给 P04/P07 复核。
- 产品为本地即开即用，无应用登录、注册或用户管理；UI 基线采用 shadcn/ui，见 `AGENTS.md` 与 `docs/design/UI_DESIGN.md`。
