## Dead ends

- The first migration rebuild attempt failed because the `plan_approvals_require_matching_pass` trigger still referenced `risk_decisions` while SQLite rebuilt that table. Dropping the trigger before the rebuild and recreating it afterward made the migration tests pass.
- Approval checks based only on any historical PASS would allow a previous PASS to be used after a newer REJECT. A stable per-version `decision_no` and latest-decision trigger check now reject that path; the regression test covers it.
