# P06-05 六字段交接

## Objective

完成 [P06-05 / #46](https://github.com/OYLPY/stock-monitor/issues/46)：提供回测参数草稿、实验与费用/风险状态、纸面账本和模拟订单状态；没有可核验证据时显示 `NOT_VERIFIED`。固定本金只允许通过用户明确确认的本机开户操作写入，不提供真实交易或直接下单路径。

## Established facts

- 本机数据库有账户、只追加账本事件与现金分录表；此前没有 UI 读取入口，也没有回测、成本/FX 或模拟成交运行时。
- 测试数据库未初始化账户；生产页面读取本地 SQLite 后显示“纸面账本未建立”，不显示推算本金或权益。
- 没有接入历史行情、外部市场服务或账户凭据。回测收益、评分、费用、权益曲线和订单状态均无可核验记录。
- 初始化仓库方法会将配置版本对应的初始资金写成唯一 `ACCOUNT_OPENED` 现金流水；此状态此前没有用户可操作入口。
- 当前数据限制仍成立：本机可建立纸面开户现金，但在无可核验行情与估值引擎时不代表可回测、可算当前权益或可模拟成交。

## Applied changes

- `src/db/paper-account-repository.ts` 新增只读账户/账本查询；`src/features/paper-account/paper-account-center.ts` 通过既有数据库入口加载快照并在读取失败时返回独立不可用状态。
- 新增 `/backtests` 页面与参数、结果、费用/风险、权益、账本、模拟订单各区块；回测参数只作为 GET URL 草稿。没有引擎/数据时禁用执行，未开户时明确显示未建立。
- 在 [P06-05 实现提交](https://github.com/OYLPY/stock-monitor/commit/be6e6173a89099153c1af91d0310b3f631b7173b) 修正 React 表单输入为可编辑的 `defaultValue`，并给账本滚动区域提供有效无障碍名称；补充 repository、页面和应用导航测试。
- 更新 `docs/design/UI_DESIGN.md`、DOC-0017 索引与 `docs/requirements/TRACEABILITY.md`。
- 增加 shadcn `AlertDialog` 明确开户确认与可重试错误反馈；本机 `POST /api/v1/paper-account/initialize` 校验 loopback 来源、UUIDv4 幂等键及确认 DTO，严格限制请求体，并只使用固定配置初始化。重试只返回现有账户状态，不重复写开户流水。
- 纸面账户页从已验证 `ACCOUNT_OPENED` 现金事件显示 1,000,000 JPY 开户现金及其 2% 初始金额 20,000 JPY；行情/估值缺失时当前权益、回撤、回测和订单仍保持不可用/`NOT_VERIFIED`。
- 更新 DOC-0009 API 契约、DOC-0017 UI 规范、文档目录、需求追踪与 Issue 索引。
