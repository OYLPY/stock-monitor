## Applied changes

- 新增 `src/lib/api/request.ts`：流式读取时执行 64 KiB 上限、JSON/UTF-8 解析、异步 Zod 校验；验证响应只含稳定错误码和已脱敏字段路径，不回显输入、值或 Zod 消息。
- 新增 `src/lib/api/errors.ts` 与 `src/lib/security/logging.ts`：统一成功/错误信封、HTTP 状态、`no-store`、服务端 request ID；意外错误只输出 request ID 和固定业务码。
- 新增 `src/lib/security/local-request.ts`：仅接受匹配 Host 的 HTTP loopback 请求；变更方法要求同源 Origin，缺失或 `null` 时按同源 Referer 校验，不读取转发头。
- 新增 API 与来源校验测试；更新 `.env.example`、DOC-0009 状态/PMO 索引和 RQ-001/RQ-025 追踪。
