# P09-02 — 无未来函数的回测撮合引擎

## Objective

完成 [Issue #59](https://github.com/OYLPY/stock-monitor/issues/59)：实现可确定性重播的供应商无关撮合核心，严格使用信号之后的下一交易时段开盘，并记录费用、结算、公司行动与可信状态。

## Established facts

- 前置 Issue #58、#31 均已关闭；实现前 `main` 与 `origin/main` 同步于 `8a6ed2a89e13e1505c51f8e43d3feb55342aefc8`，没有开放 PR。
- `runBacktest` 是纯内存单市场、单证券、单报价币种执行入口；不调用行情供应商、数据库或真实交易接口。
- 撮合只使用未复权开盘价。开盘时点不晚于信号时点的价格不成交；公司行动必须严格早于生效开盘可用，无法验证时不宣称可信。
- 结果保留逐笔行情来源、有效期费用版本、结算时间/来源、输入 SHA-256 和 `VERIFIED` / `NOT_VERIFIED` / `DEMO_ONLY` 状态。
- 美股 #49 和日股 #50 的来源授权/历史覆盖仍独立跟踪；它们不阻止无供应商计算内核，但本次没有真实历史行情输入。

## Applied changes

- 实现提交 [`43f36469ef29f5f68a0f15c3aba105d182b6d238`](https://github.com/OYLPY/stock-monitor/commit/43f36469ef29f5f68a0f15c3aba105d182b6d238)：新增 `src/features/backtest/engine.ts` 和 16 项撮合 Fixture 单元用例；同步回测设计、P09 路线图、backlog、Issue 索引、文档索引和需求追踪。
- 引擎处理点时信号、开盘全额或全无撮合、tick/价差/滑点/费用版本、累计成交量上限、已结算资金、多头持仓、带时间戳的卖出结算、拆股、分红及缺口。
- 校正恰好在开盘时点获知拆股的边界：必须在开盘前严格可用，否则停止后续撮合并将相关权益标缺失。
- `FIXTURE` 派生输出固定为 `DEMO_ONLY`；费用、结算或数据证据缺失时不升级为可信结果。未加入真实数据接入、数据库持久化或页面调用。
