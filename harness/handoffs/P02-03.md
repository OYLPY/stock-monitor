# P02-03 交接

## Objective

设计六角色研究工作流：选用同一模型按职责串行执行；角色有明确输入/输出与权限；结构化输出先由应用层验证；AI 风控可否决但不能覆盖确定性风险、计划批准或账本规则。

## Established facts

- PRD 明确六个角色可以是同一次 Codex 研究任务的步骤，不要求六个独立 Agent。
- FR-Research 的研究裁决 `APPROVED_FOR_PAPER_REVIEW` / `REJECTED` / `UNRESOLVED` 与 FR-Trade 对具体计划使用的 `PASS` / `REJECT` / `UNRESOLVED` 是不同契约；设计保持原有结果码。
- 风控和模拟成交由确定性服务执行；本地批准绑定不可变计划版本；模型无账本写权限。
- 产品本地即开即用，无应用登录/用户管理；Codex 执行器认证不作为产品登录。
