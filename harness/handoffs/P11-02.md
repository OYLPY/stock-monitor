## Applied changes

- Added [`market-watch.ts`](../../src/features/market-watch/market-watch.ts) and registered `MARKET_WATCH`. It evaluates the current execution instant, skips weekends/holidays/lunch/out-of-session windows, returns `CALENDAR_UNAVAILABLE` for uncovered calendar dates, and returns `BLOCKED_EXTERNAL/SOURCE_UNAVAILABLE` for open windows until a real Provider and validated SLA exist.
- The handler marks freshness `UNKNOWN` and signal evaluation `NOT_RUN`; it never produces `NO_NEW_EVENTS` or a signal. Calendar date, timezone, status, source version, check time, and active UTC session bounds are stored in the task completion event.
- Extended task handler results with JSON-safe details and persist those details to `task_run_events`; added rejection coverage for non-JSON handler evidence.
- Changed the market-calendar imports to relative `.ts` paths because the isolated Node Worker does not resolve `tsconfig` aliases.
- Updated [DOC-0032](../../docs/design/SCHEDULER.md), [traceability](../../docs/requirements/TRACEABILITY.md), and [document metadata](../../docs/pmo/DOCUMENT_INDEX.md).
