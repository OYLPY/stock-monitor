## Applied changes

- Added [collectors.ts](../../src/providers/disclosures/collectors.ts) and [collectors.test.ts](../../src/providers/disclosures/collectors.test.ts):
  - SEC Submissions: padded CIK, contact User-Agent, strict recent-filing field/array validation, and a persistent local rolling 10 requests/second reservation.
  - BOJ `getDataCode`: response/series/observation coverage validation, 250-series and 60,000-observation limits, persistent local one request/second reservation, and historical observation periods kept distinct from release times.
  - BLS v1: 25-series and 10-year query limits, persistent local rolling 25 requests/24 hours, and delayed historical observation records.
  - Federal Reserve RSS: explicit official HTTPS feed URL, no redirects or DTD, official item-link validation, bounded streaming response reads, parsed publication times, and a persistent local one request/minute reservation.
  - Request/schema/coverage failures return `NOT_VERIFIED` without persisting citations. Source changes create superseding versions; same-source stable IDs reached via different URLs remain one record. Raw payloads are not stored.
- Extended `recordDisclosureCitation` to support `OTHER` historical observations and SHA-256 content fingerprints while keeping the previous serialized hash shape for existing default `DISCLOSURE` citations.
- Added `fast-xml-parser` 5.12.1 for safe RSS parsing.
- Updated [DATA_PROVENANCE](../../docs/design/DATA_PROVENANCE.md), [source research](../../docs/research/data-sources.md), [DOC-0012/DOC-0036 metadata](../../docs/pmo/DOCUMENT_INDEX.md), [RQ-028 traceability](../../docs/requirements/TRACEABILITY.md), and the issue index. No UI changed.
