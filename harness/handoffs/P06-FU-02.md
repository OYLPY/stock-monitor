# P06-FU-02 — 报告与市场监测信息层级重构

## Objective

完成 GitHub [Issue #94](https://github.com/OYLPY/stock-monitor/issues/94)：让报告结论、证据联系、持久任务队列和美日行情状态可快速理解；桌面、键盘和 320px 浏览器验收通过后提交并确认 CI。

## Established facts

- 实施基线为 `main` / `origin/main` 的 `793ffb0`，当时没有开放 PR。
- 报告任务保存于本机 SQLite；列表之前缺计划时间和清晰结果摘要。市场日历是有期限的静态快照，不能代表实时行情。
- 美股 EODHD Free 凭据未配置；没有对 EODHD 或用户数据库发请求。日股未接入自动行情源。
- UI 使用已安装的 shadcn 组件；未改动 `src/components/ui/*` 或生成组件源码。

## Applied changes

- 报告页：有活动任务时默认显示持久化队列表；带报告搜索/类型筛选时，刷新仍显示报告结果。表格增加计划/提交 JST 时间、可读结果和键盘可聚焦滚动区域。
- 报告内容：首屏只显示一条与已保存事件共享证据编号的重点推论；事件/时间/市场/证据默认折叠，明确说明证据关联不构成因果。未关联时不显示推论为事件结论。
- 市场页：美股/日股并列显示最近完成交易日、静态日历状态、来源核验时间、本机覆盖/核验状态和下一步；数据导入、图表与逐条历史按需展开。
- 日历：报告与市场页共用最近完成交易日计算，未覆盖年份安全返回无法核验。
- E2E：临时数据库里加入明确标注的演示事件/推论关联；E2E 启动期间禁用 Worker，避免浏览器验收处理后台任务。
- ESLint 忽略 Next 的 `.next-*` 输出目录，避免本机生成文件被当作源代码扫描。
