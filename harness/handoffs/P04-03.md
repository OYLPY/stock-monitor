## Established facts

- The source report is current as of 2026-11-16 and uses official SEC, FSA/EDINET, JPX/TDnet, J-Quants, Nasdaq, NYSE and Alpha Vantage pages. It separates documented facts, inference, and untested access/terms.
- SEC EDGAR provides filing and structured financial disclosure data, not stock quotes. Its public investor API does not require a key; fair-access rules require a declared User-Agent and cap requests at 10 per second.
- EDINET API v2 requires an API key. No EDINET account, key or API request was used.
- JPX public TDnet pages retain recent disclosures for 31 days; Listed Company Search covers up to 10 years. The TDnet API is paid and returns five years of history. J-Quants Free provides daily OHLC with a 12-week delay and a two-year window; paid plans list five, ten or twenty years, with prices recorded in the source report.
- No reviewed free official source provides multi-decade daily OHLC for both markets. Official multi-decade Japanese and US historical products have paid and product-specific terms. Public pages are not evidence of API access, long-term storage or redistribution rights.
- Alpha Vantage's limits and real-time/delayed data statements are identified as vendor claims; no account, API key, price quote or data response was obtained.
- No live provider, news source, or production adapter was selected or connected. No paid access, credential reads, API calls or market-data payloads were used.
