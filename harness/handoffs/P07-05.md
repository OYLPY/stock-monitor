# P07-05 Handoff

## Objective

- Issue and link: [Issue #52](https://github.com/OYLPY/stock-monitor/issues/52)
- Original objective and acceptance: Normalize persisted official Fed/BOJ RSS headlines as market-level events; preserve stable source identity, timestamps, time zone, content hash and source evidence; append revisions without duplicate events; reject invalid/future/untrusted records; block real-time signals when verified quotes or volume are missing. The full acceptance contract is in Issue #52.

## Established facts

- #51 / P07-04 is the sole dependency for official RSS event archiving. #49 and #50 remain hard blockers for quote/volume-driven signals and historical performance claims.
- `collectReportSources` already persists official Fed/BOJ RSS references; the event-center UI reads the persisted market-event repository. No user database or Worker was used in this task.
- Market watch already fails closed while an exchange is open and no market-data provider is registered. This change reports freshness as `NOT_VERIFIED` and leaves `signalEvaluation` as `NOT_RUN`.
- `src/db/schema.ts` installs append-only triggers on `source_records`; legacy source metadata must be corrected through a superseding record, not an in-place update.

## Applied changes

- Added `src/features/events/normalizer.ts` and its tests. Official Fed/BOJ records become market-level events with source evidence; source identity is `(provider, recordKey)`, exact retries are idempotent, and new source versions append event revisions. Missing/mismatched time zones and future/invalid timestamps are rejected. The normalizer does not infer article text, securities, event importance, or market impact.
- `src/features/reports/task.ts` persists normalized events during report-source collection and records event counts plus the quote/volume signal limitation in source status.
- Fed/BOJ RSS citations preserve their official source time zones. A legacy record whose time-zone metadata changes gets an append-only source-record revision.
- Market-watch freshness changes from generic `UNKNOWN` to `NOT_VERIFIED` while a market is open without trusted quotes.
- Updated P07-05 scope/dependency in `docs/DEVELOPMENT_PLAN.md` and `docs/backlog/part-07-13.json`, and marked affected RQ/FR rows partial in `docs/requirements/TRACEABILITY.md`.
- Implementation commit [`47a1004b4f39c26275b44c9303299adc63c556e0`](https://github.com/OYLPY/stock-monitor/commit/47a1004b4f39c26275b44c9303299adc63c556e0) is pushed to `main`; matching [Quality CI 44511845436](https://github.com/OYLPY/stock-monitor/actions/runs/44511845436) succeeded.
