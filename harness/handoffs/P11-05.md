## Applied changes

- Added a loopback-only, no-store persisted notification polling endpoint with stable cursor ordering and strict cursor validation.
- Added the opt-in browser notification control in `/tasks`. Permission is requested only after explicit activation; quiet mode advances the cursor without replaying old alerts; polling is limited to persisted alerts while the page is open.
- Added the idempotent v15 migration restoring four immutable notification triggers while preserving the known legacy v14 checksum and existing database records.
- Added Windows Task Scheduler and macOS LaunchAgent guidance. The application does not register OS jobs automatically and does not run while the computer is asleep or off.
- Updated API, database, scheduler, user, requirements, PMO, and document-index records. No shadcn-generated component files were modified.
