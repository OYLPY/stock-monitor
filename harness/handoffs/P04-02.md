## Dead ends

- Drizzle's regular SQLite integer mapping uses JavaScript `number`; its built-in BigInt mode uses BLOB storage. For the required SQLite INTEGER representation, the PoC uses `customType` and the driver's BigInt mode.
- Drizzle Kit generated the initial migration as `0000_initial.sql` without STRICT. The migration adds STRICT explicitly and asserts the live table definition; the snapshot does not preserve this option, so generated SQL needs review after schema changes.
