# P06-06 六字段交接

## Objective

完成 [P06-06 / #47](https://github.com/OYLPY/stock-monitor/issues/47)：提供诚实标注不可用状态的设置、任务/日志/通知页面，接入可执行的本机 SQLite 备份，并用桌面、窄屏和键盘路径完成 Playwright 验收。

## Established facts

- 当前生产代码已有 SQLite Online Backup API 和数据源/事件/纸面账户存储，但没有生产设置存储、模型执行器、后台任务运行时、执行日志或通知存储。
- 设置页将数据源与模型标为 `NOT_VERIFIED`；任务页对任务、日志和通知同样明确标为 `NOT_VERIFIED`，没有显示虚构的配置、任务数量或通知数。
- 本机备份 API 使用既有备份核心和应用数据路径；成功时写入唯一 `backups` 子目录。秘密哨兵未出现在 HTML、API 错误或备份清单中。
- Next 16 将请求 URL 主机规范化为 `localhost`，而 `Host`/`Origin` 保留 `127.0.0.1`。来源保护原先因此拒绝实际本机备份；当前实现仍要求 loopback、相同端口及与 Host 匹配的 Origin/Referer。
