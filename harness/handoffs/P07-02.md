## Established facts

- 用户授权直接在 `main` 实施，无 PR；项目禁止未经授权付费数据服务。#48 与 #40 已关闭，前置依赖满足；当前仓库没有开放 PR。
- Alpha Vantage 官方 [Terms of Service](https://www.alphavantage.co/terms_of_service/) 将超出个人用途的使用列为商业用途条件，并在该项下列出投资分析、研究、测试和监控等活动。不能据此推定本项目的个人研究符合免费许可，具体适用性没有书面确认。
- Alpha Vantage [免费 API key 说明](https://www.alphavantage.co/support/api-key/)称多数数据集为每日 25 次；无限请求只适用于经确认的开源/教育项目，本项目资格未确认。当前没有 API key；没有注册、调用 API 或读取真实载荷。
- 官方 [TIME_SERIES_DAILY 文档](https://www.alphavantage.co/documentation/)说明免费 key 的 `compact` 只有最近 100 个数据点，完整 25 年以上的 `full` 数据需要 Premium；复权日线、实时及 15 分钟延迟行情也需 Premium。当前禁止付费服务，所以该来源不能满足数十年验证的行情范围。
- TOS 未在本次核验中明确本地长期保存/缓存期限和离线回测保留权。官方 API 文档仍列免费 `compact` 只返回最新 100 点，完整 25 年以上日线需 Premium。
- Tiingo 官方 Starter 价格页列出 30 年以上历史价格；但其当前发布的 [Terms of Use §1.6](https://www.tiingo.com/tos/)禁止 Starter/Trial 用户持久保存行情及派生产品，并要求计算和会话结束前删除。该计划不允许把行情或回测结果写入项目 SQLite；§1.7 另有 AI/ML 使用限制，项目使用方式未获许可确认。没有注册、申请 token 或请求 API。
- 完整来源结论见 [DOC-0036](../../docs/research/data-sources.md)。
- Twelve Data 官方[历史价格说明](https://support.twelvedata.com/en/articles/5656039-how-to-get-historical-prices)称多数证券日线覆盖自首次交易以来的完整历史，每次最多 5,000 条；其[美国市场页](https://twelvedata.com/exchanges/stocks)列出的历史范围从 1980 年起。其[套餐页](https://twelvedata.com/pricing)将免费 Basic 标记为 `Internal non-display usage`，`Internal display data access` 则列在付费 Grow 套餐；服务条款要求遵守文档中的缓存期限，本次未确认本地应用能否留存数十年 OHLCV 用于图表和回测。该 API 需要账户和 key；未注册、未申请 key、未请求接口。
- Alpaca 官方[行情计划文档](https://docs.alpaca.markets/us/docs/about-market-data-api)列出 Basic 免费实时行情仅覆盖 IEX、历史起点为 2016 年，并将历史数据限制列为 `latest 15 minutes`（计划表未解释该短语的具体语义）；Algo Trader Plus 当前列价 99 美元/月且无该限制，但历史起点仍为 2016 年。两档都不足数十年历史；API 凭据未申请或使用。
