# P11-06 / #91 六字段交接

## Objective

在晨报、日审计和周审计研究开始前采集官方宏观与央行来源，把持久证据及采集状态交给报告工作流；来源失效时安全降级，无合格股票 OHLCV 时策略候选为零。[GitHub Issue #91](https://github.com/OYLPY/stock-monitor/issues/91)

## Established facts

- 本地项目为 Next.js + SQLite + 独立 Worker；#91 的前置 #51、#56、#69 已关闭。
- BLS API 的实际载荷为 Results.series 对象；BLS CPI/就业是延迟序列。BOJ FM08 FXERD04/05 是每日参考汇率观察值。Fed/BOJ RSS 只提供标题和链接；本地 sourceRecord 不保存完整公告正文。
- 2026-11-19 JST 对四个官方端点完成一次只读 smoke，响应均 HTTP 200；请求时间、响应 schema、币种/时间语义和边界已记录在 [验收记录](../evidence/P11-06-followup-91.md) 及 [DOC-0036](../../docs/research/data-sources.md)。
- 股票 OHLCV 仍因许可/覆盖门槛未接入。没有报告模型实际运行、实时市场扫描、回测或纸面成交证据。
- 2026-11-19 复核 JPX J-Quants 官方规格：Free 计划要求先注册、股票 OHLCV 只有两年历史且滞后 12 周；NYSE 历史行情产品列有订阅与额外历史数据费用。见 [J-Quants 数据规格](https://jpx-jquants.com/en/spec/data-spec)、[J-Quants Quickstart](https://jpx-jquants.com/en/spec/quickstart)、[NYSE 历史数据价格](https://www.nyse.com/publicdocs/nyse/data/NYSE_Historical_Market_Data_Pricing.pdf)。这些方案不满足现有数十年历史与无未授权付费的门槛。

## Applied changes

- 实现报告前 BLS、BOJ FX、Fed RSS、BOJ RSS 采集和持久引用注入；补充 BOJ 空值/东京当前日期过滤、实际 BLS response schema 解析、来源降级状态。

- 更新来源、工作流、追踪和阶段文档；完整验收事实见 [P11-06 evidence](../evidence/P11-06-followup-91.md)。
- 实现提交 [`62c63d37ed0e1cd1a683fe9ec3915ad232fd7552`](https://github.com/OYLPY/stock-monitor/commit/62c63d37ed0e1cd1a683fe9ec3915ad232fd7552) 已推送 main；Quality CI [44472642104](https://github.com/OYLPY/stock-monitor/actions/runs/44472642104) 成功。

## Verification

- format:check、lint、typecheck、test（48 files / 283 tests）、build、Playwright E2E（6/6）、git diff --check 均 exit 0。
- file-backed 测试验证 sourceRecord SQLite 重启可追溯、重复任务事实记录幂等、来源失败降级；工作流测试验证来源引用传递及无行情零候选。
- 真实来源 smoke 是只读公开端点请求，不含 API key、注册、付费操作或原始响应凭据。

## Dead ends

- Node 原生 strip-types 无法可靠加载带路径别名及 extensionless imports 的 TS task handler；使用项目直接依赖 tsx 的 ESM loader 后，worker handler 集成测试和 E2E 通过。
- 默认 SQLite busy timeout 200 毫秒导致本机 Next.js/Worker 并发写入偶发 SQLITE_BUSY；统一等待设为 5 秒后 E2E 通过，锁争用单测显式保持 200 毫秒。
