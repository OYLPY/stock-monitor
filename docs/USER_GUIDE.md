# 量化研究工作台使用指南

> Doc ID: DOC-0040 · 目录：[DOCUMENT_INDEX](pmo/DOCUMENT_INDEX.md)

## 适用范围与当前边界

本工具在本机运行，无登录、注册或用户管理。它用于研究美国和日本上市的普通股票与非杠杆 ETF；不连接证券账户，不执行真实下单，也不支持杠杆、期权或做空。

以 2026-11-19 的仓库实现为准：

- 「市场监测」页明确显示尚未接入经过核验的行情来源，交易日历和开闭市状态也不会由电脑时钟推测。
- 用户可导入自己有权在本机保存的日线 CSV 并查看记录；这些记录仍标记为 `NOT_VERIFIED`，不等于授权行情源，也不进入已核验回测。
- 「设置」页的数据源适配器和本机模型执行器均为 `NOT_VERIFIED`。代码中存在的来源采集器或设计说明，不代表此安装已配置、运行或拥有完整覆盖。
- 报告请求会先保存到本机任务队列。任务显示 `PENDING` 只表示已排队；必须有可用的本机 Worker 和已接通的执行器，报告才可能完成归档。当前「任务与通知」页没有任务历史、执行日志或通知管理。
- 没有可信行情和关键证据时，报告只能标记 `NOT_VERIFIED`，不生成策略候选、回测绩效或模拟成交。页面空白也不代表没有新闻或异常。

## 先看懂状态标签

任务执行、来源覆盖、数据类别和报告验证等级是不同状态，不能互相替代。

| 标签                | 含义                                            | 使用时的判断                                   |
| ------------------- | ----------------------------------------------- | ---------------------------------------------- |
| `VERIFIED`          | 本报告需要的事实和溯源可核验                    | 不代表策略盈利、结论正确或未来仍有效           |
| `PARTIAL`           | 只有部分必要证据可用                            | 先读报告列出的缺口；依赖缺失输入的结论受限     |
| `NOT_VERIFIED`      | 核心来源、时效、证券映射或风险输入缺失/无法核验 | 不作为实时信号、回测结论或风险批准             |
| `DEMO_ONLY`         | 内容来自隔离的 Fixture/演示样本                 | 只用于展示与测试，不是市场事实、绩效或账本记录 |
| `REAL`              | 数据来自实际来源而非 Fixture                    | 本身不保证及时、准确、完整或获准用于保存/回测  |
| `DELAYED`           | 来源明确声明数据有延迟                          | 延迟不等于新鲜；检查具体市场时间和采集时间     |
| `HISTORICAL`        | 数据属于过去的市场时段                          | 不能冒充实时报价                               |
| `FIXTURE`           | 合成或测试数据                                  | 必须与真实研究数据分开                         |
| `STALE` / `UNKNOWN` | 已超过有效时限，或时效无法判断                  | 不可用于实时触发；未知不等于无异常             |

来源角色按事实类型判断：监管/交易所披露、发行人原始公告、官方宏观数据、获准行情供应商和二手新闻承担不同作用。新闻聚合可辅助发现，不能替代所需的权威来源；不存在适用于所有事实的单一可信度分数。查看报告中的来源、市场时间、采集时间、币种、延迟说明和限制。

## 页面使用步骤

### 总览 `/`

1. 从「研究工作区状态」查看各模块当前状态。
2. 选择对应模块进入市场、事件、报告或回测页面。
3. 对 `NOT_VERIFIED` 卡片先检查缺失来源；不要把空图表或空列表读成市场平静。

总览是状态入口，不是实时行情面板，也不提供盈利预测。

### 市场监测 `/markets`

1. 先阅读页面顶部的数据来源状态。若显示未接入/未核验，页面不会给出开闭市结论或可信行情快照。
2. 要查看自己提供的日线文件，在本机 CSV 区选择市场和证券标识，选择文件，并确认有权在本机保存该文件后再导入。
3. CSV 使用 UTF-8 编码，最多 4 MiB、50,000 行。必需表头为 `Date,Open,High,Low,Close,Volume`；`Symbol`、`Ticker` 或 `Ticker Symbol` 可选。日期为 `YYYY-MM-DD`，每个文件的交易日期不可重复；若填写证券标识，文件中的标识必须匹配。
4. 解析器按日线 OHLCV 字段保存数据，不读取或验证复权信息；分钟线和公司行动调整未接入。导入后可查看本机记录和图表；来源、许可、币种及行情调整状态仍须自行核验，状态不会自动升级。

本机 CSV 目前是查看入口，不是已授权行情 Provider，不能据此启用策略评分、回测或纸面下单。

### 异常与事件 `/events`

1. 用页面筛选条件缩小市场和验证状态范围，执行筛选。
2. 打开事件记录，查看事实、事件时间、来源记录和相互支持/反驳关系。
3. 来源不可用、覆盖不完整或数据过期时，以显示的缺口和状态为准。没有记录不能解释为「没有新事件」；只有完整、必需来源均有效的扫描才能得出无新事件结论。

### 晨报与策略研究 `/reports`

1. 用关键词和报告类型筛选已归档记录；类型包括晨报、异常报告、日度审计和周度审计。报告内容可展开查看摘要、事实与判断、策略候选、风控意见、来源覆盖和账本状态。
2. 选择需要的报告类型并提交生成请求。页面会先提示任务排队；如果状态保持 `PENDING`，这不是报告已生成。检查本机 Worker/执行器是否实际运行，当前任务页不提供任务历史或日志。
3. 阅读报告时，分别核对任务状态、验证等级、数据类别、来源状态及其时间戳。`DONE` 只表示任务结束，不自动表示 `VERIFIED`。
4. 只有来源覆盖、行情时效和关键风险输入足够时，报告才可能提出策略候选；数据不足时允许零候选并标 `NOT_VERIFIED`。

报告中的六个职责是统筹、情报侦察、市场结构、策略研究、独立风控和模拟交易计划。它们是报告分工，不表示六个独立部署的 Agent；角色意见也不能替代程序化风控或用户批准。

计划的报告时刻使用 `Asia/Tokyo`：晨报 07:00、日度审计 16:00、周度审计周一 07:30。定时计划只有在本机 Worker 运行且设备可用时才可能处理；错过的盘中窗口不能补写成实时扫描，定时计划也不代表行情源或模型执行器已接通。

### 回测与模拟账户 `/backtests`

1. 在「回测研究」中选择市场、证券标识、周期和日期范围。
2. 使用「应用参数草稿」保存/分享查询条件；它只写入页面 GET 地址，不启动回测或写入账本。
3. 仅当页面确认有可用的历史数据和回测引擎时，才可继续实际回测。目前条件未满足时，「开始回测」保持禁用，结果显示未核验。
4. 切换到「纸面账户」查看本地账本状态。账户未显式初始化时，不显示推算的 1,000,000 JPY、本金余额、权益或持仓；无可信价格时也不估算这些数字。

### 设置 `/settings`

1. 查看「数据源」和「模型」状态。当前页面显示 `NOT_VERIFIED` 时，不要假设供应商、权限、覆盖或执行器已经连通。
2. 在「本机备份」中创建 SQLite 一致性快照。确认页面返回成功及备份文件位置，再执行其他数据库维护操作。
3. 恢复步骤和文件校验要求见[备份与恢复手册](operations/backup.md)。不要通过手动删除数据库、迁移记录或备份来绕过错误。

### 任务与通知 `/tasks`

本页说明目前哪些后台能力已接入。报告任务状态要回到报告页查看；任务历史、执行日志及本机通知管理当前尚未提供。页面标记 `NOT_VERIFIED` 或 `尚未接入` 时，不表示有后台扫描持续运行。

## 研究与纸面账户风险说明

- **范围**：仅美股/日股普通股票和非杠杆 ETF；禁止杠杆、期权、卖空、真实交易和证券账户连接。
- **起始资金**：只有账户显式初始化时，才会写入 1,000,000 JPY 的 `ACCOUNT_OPENED` 事件。初始化前不存在可供风控使用的余额、权益或历史峰值。
- **单笔风险**：每笔计划风险不超过当期可核验权益的 2%；初始权益为 1,000,000 JPY 时预算约 20,000 JPY。报价、汇率、费用或账本不能核验时，结果应为 `UNRESOLVED`，不能以默认值批准。
- **回撤门禁**：权益相对可核验历史峰值达到 20%（包含等于 20%）时，拒绝新增头寸。该门禁不自动平仓。
- **损失可能超过预算**：跳空、停牌、流动性不足、费用、汇率和滑点可能令实际纸面结果差于模型；止损触发价不是成交保证，2% 不是最大实际损失保证。
- **策略评分**：样本外稳定性、扣费后收益、最大回撤、成交可行性和跨环境稳健性各按 1–5 分。只有实证数据充分时，18/25 以上才可作为继续验证候选；评分不是批准、收益承诺或自动升级。
- **回测限制**：历史结果依赖当时可获得的数据、证券映射、公司行动、费用、汇率、日历及执行假设。样本内表现、样本外结果和压力测试都不能保证未来表现；缺数据时不得报告虚构胜率或绩效。
- **模型边界**：模型可整理证据和提出假设，不能决定资金、改变固定风险限制、批准真实订单或伪造账本。确定性风控与账本必须基于可核验证据。

## 常见问题

**为什么报告任务排队了但没有报告？** 任务已进入本机队列，但还没有证据表明 Worker 和执行器已处理它。`PENDING` 不是成功报告；此安装的模型执行器状态显示 `NOT_VERIFIED`。

**市场页没有价格，是系统故障吗？** 当前没有接入经过核验的美股/日股行情源。可查看有权在本机保存的 CSV，但该数据不自动获得可信、实时或回测资格。

**事件列表为空，是否表示没有异常？** 否。必须先确认对应市场、来源覆盖和时效都完整。缺少来源时应是 `NOT_VERIFIED`/`UNAVAILABLE`，而不是「没有新事件」。

**`VERIFIED` 是否表示策略赚钱？** 否。它表示特定报告事实及溯源可核验，不是预测正确率或盈利证明。

**纸面账户是否已经有 1,000,000 JPY？** 只有显式初始化记录存在时才有。当前页面如果显示账本未建立，就不应推断本金或收益。

**系统会自动下单吗？** 不会。本工具不连接券商、不提交真实订单，也不自动把策略候选升级为模拟成交。

**可以只根据一份旧回测开始交易吗？** 不可以。回测不是未来保证；应检查样本外、压力测试、数据来源、交易成本和风险证据。缺任一关键输入时继续观察或标 `NOT_VERIFIED`。
