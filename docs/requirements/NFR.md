# V1 非功能需求（NFR）

> 状态：P01-04 验收基线；以下是后续设计与实现的目标，不表示当前原型已达到这些指标。运行验证状态统一见 [TRACEABILITY.md](TRACEABILITY.md)。
>
> 产品边界：[PRD](PRD.md)、[需求索引](REQUIREMENTS_INDEX.md)、[AGENTS.md](../../AGENTS.md)。这是无需登录、注册或用户管理的个人本地工具；确定性风险与纸面账本规则见 [FR-Trade](FR_TRADE.md)，研究来源和降级语义见 [FR-Research](FR_RESEARCH.md)。

## 适用范围与状态约定

- NFR 的运行目标仅适用于本机 Next.js 应用、独立本地 Worker 和 SQLite；Codex、行情供应商及网络服务的响应时间不计入本地页面性能 SLA。
- 所有性能阈值须由 P12 在固定测试环境复核并记录 OS、CPU、内存、Node、数据库版本和样本大小；不得把本地目标写成已验证结果。
- `NOT_VERIFIED`、`BLOCKED_EXTERNAL`、`DEMO_ONLY`、`HISTORICAL`、`DELAYED` 与 `REAL` 是不同的数据/验证状态。缺失输入不能静默替换为零、空列表或缓存旧值。
- 应用机器关机、睡眠、Node/Worker 进程停止或本地磁盘故障时，不承诺持续在线；恢复流程必须记录可证实状态。
- 每项 NFR 都有编号 AC-NFR；AC 只定义后续测试输入。实际实现和运行验证状态见 `TRACEABILITY.md`，不得将需求文档计作 P12 测试通过。

| NFR-005 | **恢复与一致性。** 本地 Worker 生命周期与浏览器分离。已确认写入的纸面账本事件在应用进程被强制终止后不得丢失（RPO=0，前提是本机存储仍可读）；对 100,000 条账本事件的基准库，正常重启恢复在 60 秒内完成。任务恢复必须幂等，不得重复成交、通知或账本副作用。                                     | AC-NFR-007–009；RQ-021、RQ-023、RQ-024；P03-01/P04-04/P05/P10/P11/P12       |
| NFR-006 | **审计可复核。** 关键任务、研究运行、风险裁决、计划批准、订单、模拟成交、费用、FX 与账本事件记录稳定 ID、类型、时间、来源/规则/策略版本、输入引用及结果/原因。纸面账本只追加，不修改或删除既有金额事件；本地单使用者不生成虚构的身份 ID。                                                     | AC-NFR-010；RQ-010、RQ-019–021；P03/P05/P08/P10/P12                         |

| NFR-008 | **凭据与本机信任边界。** Codex/API 凭据不得进入客户端 bundle、浏览器存储、响应、日志、报告、备份或 Git；服务端只保存必要的来源状态，不回显密钥。默认不连接遥测、云同步或远端身份服务；只有用户明确配置的供应商请求才可发出。外部不可信文本只能作为数据，不能扩大工具权限或覆盖安全规则。      | AC-NFR-002/012/022；RQ-018、RQ-025、RQ-031；P02-04/P03-02/P05/P08-05/P12-05 |
| NFR-009 | **数据质量和出处。** 行情、FX、事件、报告和回测输入保留来源、证券/市场、币种、市场时间、采集时间、时区及延迟/历史/Fixture 标记。来源不明、过期、冲突或不完整时降级为 `PARTIAL_COVERAGE` / `NOT_VERIFIED`；不得将“未取得数据”显示成“没有事件”。                                                | AC-NFR-013/014；RQ-010–011、RQ-022、RQ-028；P02-02/P03/P07/P08/P09/P12      |
| NFR-010 | **Fixture 隔离。** Fixture 可演示流程和验证计算，但每个派生报告、图表、策略分数及结果都保留 `DEMO_ONLY`；不得混入 `REAL` / `HISTORICAL` 的绩效统计或纸面成交账本。                                                                                                                            | AC-NFR-015；RQ-011、RQ-028；P04/P06/P08/P09/P10/P12                         |
| NFR-011 | **中文和数值呈现。** 用户可见的固定界面文案默认使用简体中文；稳定状态码同时显示中文含义。价格/收益/费用附币种，市场时间附市场时区；格式化仅用于显示，不改变账本精度和计算值。外部原文标题可保持来源语言。                                                                                     | AC-NFR-016/017；RQ-027、RQ-030；P06/P08/P12-03                              |
| NFR-012 | **无障碍和窄屏。** 关键用户流程以 W3C WCAG 2.2 AA 为目标，包括本地首次使用、查看研究证据、风险结果、账本和备份恢复。键盘可达、焦点可见且不被遮挡、表单错误可读、状态不只靠颜色表达。视口等效 320 CSS 像素时信息和功能不丢失；仅真正二维数据表可在自己的容器内横向滚动。                       | AC-NFR-018–020；RQ-027；P06/P12-03                                          |
| NFR-013 | **短上下文与可恢复交接。** Codex 执行器按任务按需读取上下文；持久化交接包含 Objective、Established facts、Applied changes、Verification、Dead ends、Remaining plan 六项。重启后先检查实际 Git/文件状态并复核相关证据；不恢复无关历史，不推断缺失或截断日志，也不丢原始 Issue 验收和安全约束。 | AC-NFR-021；RQ-029；P00-04/P08-05                                           |
