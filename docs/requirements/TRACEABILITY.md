## 状态含义

| 状态                                          | 含义                                                                                             |
| --------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| `SPECIFIED`                                   | 产品要求和对应 AC 已在 P01 文档中定义。                                                          |
| `IMPLEMENTATION_PENDING`                      | 责任设计/实现 Issue 尚未以代码和测试完成验收；不得报告运行通过。                                 |
| `IMPLEMENTED_PARTIAL`                         | 需求的部分范围已有代码和任务级测试；未完成的 AC、跨模块集成和 P12 回归仍待验证。                 |
