# UI 设计与现代 Web 实施约定

> Doc ID: DOC-0017 · metadata 以[文档目录](../pmo/DOCUMENT_INDEX.md)为准。

参考：[Chrome for Developers — Modern Web Guidance v1](https://developer.chrome.com/blog/modern-web-guidance-v1?hl=zh-cn)。

## 设计 token 与应用壳层

- `src/app/globals.css` 是 shadcn 语义色、字体和圆角 token 的唯一代码来源。组件使用 `bg-background`、`text-foreground`、`text-muted-foreground`、`border-border`、`bg-primary` 等语义 utility，不散落原始颜色值。
- 基础主题使用 neutral。`--chart-*` 仅供有来源和时效标注的真实或 Fixture 图表使用；状态必须有文字，不以红绿颜色单独表达行情方向或验证状态。
- `font-sans` 和 `font-heading` 使用系统字体栈，优先可用的简体中文字体并保留系统回退；本地运行和构建不得依赖远程字体请求。
- 字级沿用 Tailwind 语义尺度：区块标题 `text-base`、正文 `text-sm`、辅助说明 `text-xs`。数值列在对应数据页面使用等宽数字样式。
- 间距沿用 Tailwind v4 的 0.25rem 基准阶梯，布局使用 `gap-*`、`p-*` 与逻辑方向属性；圆角只通过 `--radius` 派生的 radius tokens 调整。
- 应用壳层使用 shadcn `Sidebar` 和单一 `<main>`。仅已实现的页面使用可导航链接；待开放模块显式标注状态并使用原生禁用控件，不渲染空链接或无效 Tab 停靠位。窄屏导航应可通过可见按钮打开和关闭，控件沿用官方 shadcn 默认尺寸。
- 每页仅一个 `<h1>`；跳过链接定位到带 `tabIndex={-1}` 的主内容区域。导航用 `aria-current="page"` 标示当前位置。焦点状态须在常规和 forced-colors 模式下清晰可见。
- 空数据统一使用 shadcn `Empty` 和文字状态。无已验证行情或研究结果时显示 `NOT_VERIFIED`，不生成示例价格、胜率或模拟收益。

## shadcn 组件边界

- 所有 shadcn 组件只能通过官方 CLI 安装或更新：本仓库使用 `pnpm exec shadcn add <component...> --yes`。禁止手写、复制、脚本生成组件源码，也禁止手动修改 CLI 生成的组件源码。
- 既有 `src/components/ui/*` 文件保持只读；`components.json` 将 CLI 的 `ui` alias 指向 `src/components/shadcn`，页面组件统一从 `@/components/shadcn/*` 使用已安装的官方 shadcn 源码。
- 页面直接组合 shadcn 基础组件，不另造通用控件或视觉体系。组件的 `className` 只承担布局、窄屏尺寸和焦点等用途，不覆盖官方组件颜色、字体、边框或圆角。普通 HTML 只用于页面语义和业务数据内容，不用它仿制可交互控件或通用卡片。
- 表单字段使用 `Field`/`FieldGroup` 与可见标签；筛选下拉使用 shadcn `Select`，保持 GET 参数和受控选项。输入框、按钮、状态标记、卡片、空态、表格和图表使用对应 shadcn 组件。
- 组件按交互目的选用：详情展开使用 `Collapsible`/`Accordion`；有真实侧面编辑/浏览任务时使用 `Sheet`/`Drawer`；短暂结果使用 Sonner toast；需中断处理的重要错误使用 `AlertDialog`；持续展示的状态说明使用 `Alert`；导航由 `Sidebar` 承载。没有对应交互需求时不为“用组件”增加控件。

## 产品界面原则

- 默认使用简体中文；股票、货币、时区、采集时间和市场时间应明确标注。
- 产品作为即开即用的本地工具，不展示登录、注册或用户管理流程；开发执行器的 CLI 认证不属于应用界面。
- 组件基线采用官方 shadcn/ui CLI 安装的组件，并沿用其标准样式与交互；优先组合基础组件，不手写通用控件、组件外观或额外组件体系。
- 当前页名称已由侧边栏明确表示时，内容区不重复展示大型页面标题；保留屏幕阅读器可访问的单一 `h1`，可见空间用于状态、数据和操作。仅在能强化重要记忆时重复风险上限、核验状态和数据来源。
- 同一页面包含不同任务或领域对象时按语义分组；使用 shadcn `Tabs` 或独立区块把互不相同的记录类型分开，不把它们混成一条长列表。分组标题与卡片内有用的状态信息各自承担清晰作用，避免重复类别标签。
- 作为本地研究工作台，优先呈现可读的数据表、来源与研究状态；避免无意义的装饰卡片和伪实时视觉。
- 每个外部数据视图应表达来源、采集时间、市场时间及真实/延迟/历史/Fixture 状态。不可核验时明确显示 `NOT_VERIFIED`，不得用示例行情伪装真实数据。
- 纸面模拟和研究页面不得暗示真实下单、证券账户连接或自动收益承诺。
- 桌面布局可提高信息密度；窄屏应保持阅读顺序、关键状态和主要操作可用，不依赖悬停才能完成任务。

## 市场监测、数据状态与图表

- 行情卡片明确展示市场/证券、数据来源、市场时间、采集时间、币种与单位、时区和数据状态；缺失值标明未提供，不使用当前时间、默认价格或其他来源补齐。
- 交易日历未接入或无法核验时，开闭市状态显示为未知并标记 `NOT_VERIFIED`。不得根据星期、本机时钟或固定 UTC 偏移推断市场是否开市。
- 数据状态沿用 [数据溯源设计](DATA_PROVENANCE.md)：`REAL` 仅表示来自实际来源，不代表实时；`DELAYED` 必须有来源延迟声明；`HISTORICAL` 表示已结束市场时段的数据；`FIXTURE` 及其派生结果明确标记 `DEMO_ONLY`；来源或性质未核验时为 `NOT_VERIFIED`。来源可用状态与数据状态分开表达。
- 时间序列按对应市场的 IANA 时区显示，市场时间与采集时间分开呈现。没有可核验数据点时显示空态，不绘制趋势线或示例价格。
- 市场页允许用户通过 shadcn `Field`、`RadioGroup`、`Input`、`Checkbox` 和 `Button` 导入本机 CSV；保存权确认不改变来源/许可/数据核验状态。导入记录立即以 shadcn `Table` 显示来源 hash、本机采集时间和 `NOT_VERIFIED`，不进入图表、回测、策略评分或纸面账本。
- 图表使用 SVG 时须提供可访问名称和简要描述；同时提供可展开的语义数据表，包含表标题、列标题、市场时间和带币种/单位的价格，作为非视觉替代。

## 异常与事件中心

- 事件列表按本机保存的事件 ID 展示归并簇；只展开该事件已经关联的来源记录，不以相同指纹单独合并事件。修订历史保持可展开，原始来源链接、来源角色/许可状态、来源发布时间、发生时间、本机采集时间和内容 hash 分开呈现。
- 展示事件记录中的重要性依据，但当前存储没有独立重要性等级，不能由页面自行分级。风险评估与通知状态只展示已保存的确定性裁决/通知记录；缺少记录时显示不可判定，不等同于已通过、低风险或未通知。
- 过滤只使用已保存且受控的市场和核验等级，使用带可见标签的 GET 表单、shadcn `Select` 和 `Button`，且由用户明确提交。无记录时明确说明本机事件库为空不代表市场无事件；页面不请求外部行情或新闻来源。
- `FIXTURE` 事件及证据始终标为仅演示；没有关联来源证据的修订不能显示为已验证。

## 晨报与策略研究

- 报告历史只呈现本机已保存的报告，并按报告类型分组；报告生成/归档运行时未接入或本机无记录时显示真实空态，不生成演示报告、候选或绩效数字。报告类型与文本查询使用 `Field`、shadcn `Select`/`InputGroup` 和 GET 表单，由用户明确提交；证据明细使用 `Collapsible`。
- 执行状态、报告验证等级、数据状态、来源状态及业务结果码分开显示。晨报展示五行摘要；缺行、证据缺口、失败或外部阻断均明确说明，不把候选描述为已验证策略。
- 事实、推论和假设分区呈现，并显示所引用的 evidence ID。候选最多三项；每项显示逻辑、触发/失效条件、对手情形、证据和未解决问题。超过三项的损坏报告不展示候选组并提示契约错误。
- 六个角色按统筹、情报侦察、市场结构、策略研发、独立风控、模拟员的固定顺序展示步骤状态和已保存摘要；缺少步骤记录显示为未记录，不推断为跳过或完成。
- 确定性风控裁决及其原因与模型 Risk Officer 意见分开显示。缺少裁决或原因不能表示为通过；模型未否决也不代表风控通过，模型不能改写确定性裁决。重要数据契约冲突用 shadcn `Alert` 明确呈现。
- 来源覆盖展示来源状态、数据状态、市场时间、采集时间、各自时区、币种、延迟声明及限制。仅允许无凭据的 HTTPS 来源链接；Fixture 及派生结果始终显示为 `DEMO_ONLY`。
- 账本只显示已保存的 `INITIALIZED`、`NOT_INITIALIZED` 或 `UNAVAILABLE` 状态；不可用时不推算权益、持仓、订单或盈亏。筛选使用 shadcn 表单组件，报告和行情详情展开使用 `Collapsible`，键盘可用并在窄屏保持单列阅读。

## 回测与纸面账户

- 回测研究与纸面账户使用 shadcn `Tabs` 分开；参数、实验结果、费用/风险与权益曲线属于回测研究，账本和模拟订单状态属于纸面账户。回测参数使用有明确标签的 shadcn `Field`、`Input`、`Select` 和 GET 表单；参数只保留在当前 URL 草稿中，不表示保存或已运行。运行引擎、策略版本或历史数据缺失时，执行按钮禁用并显示原因。
- 回测结果、样本边界、费用/FX 明细、验证评分和权益曲线只呈现已有的可复核运行快照。纸面账户权益曲线从开户本金和完整的 `VERIFIED` 快照重建，并同时展示最大回撤和精确金额表；账本审计不通过、快照缺失或同一市场时点存在冲突时标记 `NOT_VERIFIED`，不绘制曲线或填入回撤数字。
- 纸面账户状态从本机数据库中已保存的账户记录读取。未初始化时明确显示“纸面账本未建立”，不把固定初始资金当成已开户余额；数据库不可读时使用独立的不可用状态。
- 已初始化账本只展示真实追加事件及其原币种现金分录和记录时点；除非账本投影、持仓估值、FX 和时点证据齐全，不推算当前现金、权益、购买力或风险预算。账本表格使用语义表头和可键盘滚动的窄屏区域。
- 账本审计展示稳定的成交编号、订单编号及守恒检查错误码；权益图表启用键盘/辅助技术层，并提供可读表格作为精确数据替代。审计错误或行情证据不完整时，指标状态保持 `NOT_VERIFIED`。
- 模拟订单状态只显示已持久化模拟器记录；若订单存储/模拟器未接入，状态为 `NOT_VERIFIED`。订单创建按钮禁用，UI 不直接写入订单、风控裁决或账本。
- 单笔预计最大损失不超过可核验当前权益的 2%，权益相对历史峰值回撤达到 20% 时停止新开仓。页面只读展示固定边界，不接受可修改门槛，也不把 AI/参数输入当成确定性风控裁决。
- 全页面不提供券商连接或真实下单按钮；回测和纸面模拟均不连接真实资金账户。

## 本机设置、任务、通知与备份

- 设置页只呈现本机功能的实际接入状态。数据源适配器或模型执行器未接入时显示 `NOT_VERIFIED`；不把不存在的设置当成已保存配置，也不读取或回显 token、密钥或 Codex 隐藏推理。
- 任务状态、执行日志和通知只允许来自生产持久化记录，并按任务运行与通知分组。Worker、任务表或通知表未接入时显示不可核验状态，不把它呈现为零条记录、任务成功或“没有通知”；POC 和开发执行器日志不能作为产品数据。
- 通知仅表示本机已保存记录，不连接邮件、云推送或外部联系人。缺少通知存储时，页面不得推断未读数或已读状态。
- 本机备份动作通过 loopback API 调用已有 SQLite Online Backup 实现，写入应用数据目录的唯一备份目录，不覆盖当前数据库或已有备份。成功用 Sonner toast 显示本机目录；失败用 shadcn `AlertDialog` 呈现统一错误文本。
- 仅在实际提供的操作上显示可交互控件；不可用运行时以文本和状态标识说明，不渲染无效按钮。

## 现代 Web 指南流程

UI、CSS 或客户端 JavaScript 开发前，先阅读仓库内的 `.agents/skills/modern-web-guidance/SKILL.md`。对具体能力执行有针对性的 `search`，阅读匹配的 `retrieve` 指南，再把相关建议适配到 React、Next.js 与本项目现有组件；不要把互不相关的指南硬套到功能上。

默认以 Baseline Widely available 能力作为无回退方案。采用更晚进入 Baseline 的能力时，按相应指南实现兼容回退，除非项目明确记录了不同的浏览器支持策略。优先使用合适的原生 HTML/CSS/DOM 能力，避免仅为模拟平台已有能力而加入 JavaScript 或依赖。

## 交互与质量要求

- 使用语义正确的 HTML；主要功能可用键盘完成，并提供清晰、可见的焦点状态。
- 表单控件应有可访问名称；校验错误需关联输入项并用文字说明，不能只依赖颜色。
- 控件尺寸沿用 shadcn CLI 生成版本的标准默认值和内置变体；不以页面级 `min-h-*` 或 `size="lg"` 普遍放大按钮、输入框和下拉框。窄屏交互保持可操作，并保留键盘行为和可见焦点。
- 尊重减少动态效果偏好；动效不能阻挡输入、阅读或状态变化。
- 颜色和状态标识保持足够对比度，并同时使用文字或图标传达状态。
- 保持页面稳定，避免内容加载导致明显布局跳动；长列表和非首屏内容按相关指南控制渲染成本。
- 把远程或导入文本视为不可信数据，不直接注入未经消毒的 HTML；凭据只保留在服务端或本地可信边界内。
- UI 变更按任务验收要求检查窄屏、键盘路径、焦点、空态、错误态和数据时效；不以静态截图替代交互验证。
