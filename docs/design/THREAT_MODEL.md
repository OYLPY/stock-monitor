# 本地工具威胁模型

> 状态：P02-04 设计基线。范围限于本机 V1 架构；这是设计分析，不是已完成的安全审计或运行时防护证明。实现验证责任见 [需求追踪矩阵](../requirements/TRACEABILITY.md) 和 [NFR](../requirements/NFR.md)。

## 安全目标和边界

- 保护本机 SQLite 中的研究材料、任务状态和纸面账本完整性；保护 Codex/数据源凭据，不泄露到浏览器、报告、日志、备份或 Git。
- 任何网页、新闻、监管披露、模型输出和 Fixture 都是外部不可信数据，不能改变系统指令、开放工具权限或直接产生账本副作用。
- Next.js 只绑定 `127.0.0.1`；V1 不面向局域网或互联网，不新增登录、用户管理、云同步或远端身份服务。无应用登录是单一本机用户边界的产品决定，不等于服务可安全地暴露到网络。
- 纸面计划仍要求本机使用者对同一版本显式批准，并通过确定性风控；AI 不能批准计划、记录成交或更改固定风险阈值。

## 资产与信任边界

| 资产/边界                  | 需要保护的属性                          | 允许的流向                                                               |
| -------------------------- | --------------------------------------- | ------------------------------------------------------------------------ |
| 本机 SQLite 与备份         | 账本不可变性、研究/任务完整性、可恢复性 | 仅本机 Node 服务和 Worker 经服务端适配器访问；备份不含凭据               |
| Codex 与数据源凭据         | 保密性和可撤销性                        | 仅在需要的本机服务端/Worker 适配器中可用；不发送到浏览器或模型上下文     |
| 浏览器 → Next.js           | 请求来源、输入范围和数据最小化          | 本机同源 HTTP；浏览器不能直接打开文件或调用数据库/模型进程               |
| Worker → SQLite / 外部服务 | 最小能力、可观察失败和副作用幂等        | 经 Application 和受限适配器；外部网络仅由被配置的连接器发起              |
| 外部内容 → 研究流程        | 来源身份、时间、数据状态、抗提示注入    | 保留来源元数据并作为数据传入；输出必须通过应用结构、证据和确定性规则检查 |

## 威胁及设计控制

| 威胁                                                                      | 影响                                              | 设计控制                                                                                                                                                                                                                  | 责任/验证                                                            |
| ------------------------------------------------------------------------- | ------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------- |
| 错误监听地址或未来配置把本地服务暴露到局域网                              | 未授权远程读取/操作本地数据                       | 所有发行入口只绑定 `127.0.0.1`；端口冲突失败并明确提示，不回退到 `0.0.0.0`；禁用通配 CORS、远端隧道和公网部署                                                                                                             | NFR-001/AC-NFR-002；P12-05 检查进程监听和依赖                        |
| 恶意网站借用浏览器访问 localhost（CSRF、DNS rebinding、Host/Origin 混淆） | 触发扫描、改变设置或批准纸面计划；探测本地服务    | 所有状态变更使用非安全 HTTP 方法；精确校验 Host 与 Origin/Referer 对应的实际 loopback origin，拒绝缺失/`null`/非预期来源；不放宽 CORS；高影响动作要求页面内明确用户操作。仅依赖框架保护不够，Route Handler 也要遵守此契约 | RQ-001/025、NFR-008；P03-02 定 API 防护，P06 实现，P12-05 做跨源回归 |
| 同一 OS 用户下的本地恶意进程                                              | 调用无登录的本地 API 或读取本机用户权限范围内文件 | 把信任边界定义为单一本机 OS 账户；只暴露必要 API，不让读请求产生副作用；计划批准仍需显式动作与确定性规则；数据库和秘密文件使用本机用户权限                                                                                | 产品边界；无法防御已控制同一账户的本地程序，详见“非目标”             |
| 新闻/披露或模型输出包含提示注入                                           | 输出虚假结论、请求敏感信息或尝试改变权限          | 内容保留来源并与系统策略分离；Codex 不持有数据库/账本访问；不启用模型任意 shell、浏览器、MCP 或网络取数；解析输出并核验 evidence ID；风险和账本决定由确定性代码执行                                                       | RQ-009/025、NFR-008/AC-NFR-022；P08-05/P12-05                        |
| 不可信 URL、重定向或响应造成 SSRF/资源耗尽/解析器攻击                     | 读取本机端点、访问非预期网络或耗尽资源            | 供应商通过明确注册表配置；不提供任意 URL 抓取；限制目标主机、重定向、响应体、解析深度和请求时限；凭据只发给预期 host                                                                                                      | P02-02、P04/P07；P12-02/P12-05                                       |
| 凭据进入客户端、日志、报告、Codex 会话历史、数据库备份或 Git              | 外部账户/供应商被冒用                             | 凭据只在最小服务端环境/Worker 使用；进程只接收必要变量；日志脱敏；备份不含凭据；密钥配置不进 repo 或模型上下文；P04 核实 Codex 本机线程历史目录与保留方式                                                                 | NFR-008/AC-NFR-012；P04/P05/P12-05                                   |
| 数据库损坏、磁盘写满、权限变化或并发写入                                  | 账本/任务丢失、重复或错误                         | SQLite 事务和短写入；幂等键/唯一约束；存储异常时 fail closed；仅使用一致性快照备份并先校验恢复副本                                                                                                                        | ADR-0001、NFR-005/007；P03/P05/P12-02/05                             |
| 恶意或被攻陷的 npm/运行时依赖                                             | 本机数据泄露、任意代码执行                        | 固定 lockfile、仅引入必要依赖、CI 和依赖安全检查；执行权限继续由 OS 用户权限约束；发布升级前验证来源和版本                                                                                                                | P00-02、P12-05、P13                                                  |

## 明确不提供的保证

V1 不是多用户服务器，不能通过转发、反向代理、隧道、局域网绑定或云部署供其他设备使用。无登录意味着不能区分同一 OS 用户下的多个本地调用方，也不抵御已攻破的 OS 账户、管理员、物理访问、恶意浏览器扩展或同账户恶意进程。操作系统、磁盘损坏和用户主动删除也不能由应用事务保证；备份与恢复另按 NFR-007 实现。
